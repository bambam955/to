# Standardization

These specs will work towards standardization of the "TO" project in various aspects.

This will include areas such as CLI standard contracts, documentation, OSS standards, tooling, and CI/CD, to name a few.

This group of specs will build on the [MVP](specs/000-mvp/SPEC.md).
